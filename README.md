# Basketball Stat Tracker
#### Video Demo:  <https://youtu.be/zTpzov83J8o>
#### Description:
Hello cs50, so for my personal project I chose to create is a basketball stat tracker.
I came up with the idea from me playing basketball competitively overseas and I play in semi pro leagues locally back home.
The tool would be very convenient for anyone that struggles to get their averages or does not have anything to keep track.
Something I have came across in my basketball carrer so far is the requirements to tryout.
Most tryouts for professional teams require stat averages and game film and sometimes those aren't easy to access.
So with this tool I wanted to make it something in the future where you can pull up anywhere whether you have a phone or computer.
As long as you have the stats you can keep track of them and they will store them in the application
Another inspiration that gave me the idea to create this was my local mens league I played in.
They are on the rise becoming a very well respecting league in the area.
So recently they asked me and a few people on ideas to make the league bigger than their competitors.
Something that I told them that would separate them  for everyone is having player's stats and averages posted on their page.
Conveniently around the time of that discussion I started taking cs50 and threw the idea out that I could use that idea into my final project.
To create this project I thought the best way to execute it was using python and SQL.
Python was used to code the routes, how the data was supposed to be caculated to get the averages, and functions like adding and deleting players that are saved/tracked. I used the normal layout of a Sql application to be able to store data between sessions that were created. I included files under "templates" like the layout, index, to edit, add players, an average, and the player overall stats which all were made through HTML. So when opening the app the first thing you will see is the homepage. This includes a navigation bar that I kept simple and easy to see all that there is to offer. So the navigation bar includes three different options such as the "Home" that will navigate you back to the home page. An add player option is the next Funtion on the navigation bar and this will send you to another page to be able to add a new player to track. The last option available in the navigation bar is to send you to a different page from the others, this one will allow you to view player stats recorded.
To go more into detail of my home menu, when you start the application, I wanted to make it as easy as possible to find your way around the program. I didn't wanted it to be a head scratcher to someone that isn't too techy or has little to no knowlege. So right off you will see an easy to navigate bar which consists of "Home", "Add Player", and "Averages". I wanted to divided every function to have it's own page so there would not be any confusion for anyone using the application. A little somethign I also did was make the steps you need to make it in the order of how the navigation bar is set. You first would need to click the "Add player" page to which youll now see two options to add a player and list the team name of the team the desired player plays for. After you complete that step you'll now be sent to the "Home" page to where you'll now see that player and their team they play for. If you notice next to the player listed you'll have options on the right side to either "view stats" or to delete player. So the delete function is like it's stated and it will delete an unwanted player for whatever reason you decided he or she's stats weren't necessary any more. Now if you were to click on the "View stats" funtion it would send you to a page of the individual player you clicked on and below it will show a new funtion "Add Game" along with a table of recorded stats of Dates, Points, Assists, Rebounds, steals, blocks, and turnovers. Now it'll be empty until we go ahead and click on the "Add Game" function.
Clicking on this will send you to another page in which has different options of stat counters to choose from and an option to set the game date of your game you recorded. Now I gave the option to have an up and down arrow function to count up or down for each stat or to be able to type the stat manually. If you notice they're atomatically set to zero. This actually was intentional incase the person didn't play much this game or did not produce in the specific stats it would stay at zero. Once you type out your stats and click add game it'll send you back to the page to now see the stats appear under the table from earlier. If you have more games to record you can go back and click "add game" or something I decided to give to options to delete or edit the stats you recorded just in case you wanted to fix a stat or edit it entirely and the delete if you wish to not recorded that game anymore.
So from there you can now go to the navigation bar and click "Averages" and in there you'll now see an table of every player you have added, their team that they play for, and the average of every game stat recorded for that player.
That sums up all the app's functions. My goal with this application is for it to be a universal tool that any league or player can use to get an accurate statline of themselves or other players.
